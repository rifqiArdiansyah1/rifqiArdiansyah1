## 🚀 Featured Projects

### 🚗 [Rental Management System](https://github.com/rifqiArdiansyah1/rental-management-system)
> *Enterprise Multi-Branch Vehicle Rental & Fleet Booking Management System*

A comprehensive multi-branch vehicle rental platform with automated fleet tracking and reservation pipelines. Engineered with role-based access control (Admin Pusat, Admin Cabang, Staff Cabang), customer document verification workflows, driver assignment lifecycles, and real-time availability scheduling.

`Next.js (App Router)` `TypeScript` `Prisma ORM` `PostgreSQL / Supabase` `Tailwind CSS`

### 🌐 Web Quiz Platform
> *Secure, full-stack interactive quiz system*

A multi-user quiz platform with dynamic question handling, middleware-guarded routes, and a structured relational schema built on Neon DB. Designed with security-first principles — sanitized inputs, role-based access, and safe data parsing throughout.

`Next.js` `Prisma ORM` `Neon DB` `Tailwind CSS` `TypeScript`

---

### 🌶️ CAPS — Chili Adaptive Precision System
> *Intelligent IoT hydroponics for precision agriculture*

An automated nutrient delivery system for hydroponic chili cultivation. A multi-sensor array (temperature, humidity, pH, EC) feeds real-time data into an ESP32 controller that adjusts irrigation and feeding schedules autonomously. Built entirely from hardware up.

`ESP32` `Arduino` `Sensor Array` `IoT Data Streams` `Embedded C`

---

### 🎛️ Zenpad — 8-Pad MIDI Percussion Controller
> *Handcrafted from Dutch Teak wood, powered by a microcontroller*

A fully custom MIDI controller: 8 velocity-sensitive pads built on piezo sensors, routed through custom firmware running on an Arduino Pro Micro. The enclosure is hand-routed from solid Dutch Teak. Every component — hardware, wiring, and firmware — designed and built from scratch.

`Arduino Pro Micro` `Piezo Sensors` `MIDI Firmware` `Woodworking`
